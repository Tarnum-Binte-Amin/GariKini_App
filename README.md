🚗 GariKini - Android Vehicle Marketplace App
GariKini is a feature-rich, native Android marketplace application designed for buying and selling vehicles. Developed as a frontend design and mobile development internship project, it provides a seamless and modern user experience for automotive classifieds using Java, XML, and Material Design components in Android Studio.
✨ Features & Functionality
- Animated Splash Screen: Features a polished, 3-second animated splash screen on startup.   
- Secure User Authentication: Complete authentication workflow equipped with robust input validation forms.   
- Dynamic Home Feed: A responsive, grid-based home feed pre-loaded with sample vehicle listings to explore.   
- Full Activity Navigation: Smooth, intuitive navigation across multiple activities throughout the application.   
- Real-Time Location Filtering: Search and filter vehicle options dynamically based on location preferences.   
- Interactive Post Creation: An interactive "Add Post" workflow allowing users to easily publish new vehicle marketplace entries.   
- Comprehensive Detail View: Detailed breakdown of vehicle specifications paired with direct seller contact triggers.   
🛠️ Tech Stack & Tools
- Language: Java   
- UI/Markup: XML, Material Components   
- IDE: Android Studio   
- Version Control: Git & GitHub   
📱 How It Works (App Workflow)
1. Launch: Users are greeted with a smooth 3-second animated splash screen leading into the application flow.   
2. Authentication: New or returning users navigate through secure login and registration screens featuring input validations.   
3. Explore Marketplace: Upon logging in, users land on the dynamic grid-based home feed displaying pre-loaded and user-generated vehicle listings.   
4. Filter & Inspect: Users can apply real-time location filters to narrow down choices and tap on any listing to view comprehensive details, specs, and seller contact options.   
5. Post Listings: Users can utilize the interactive add-post feature to input details and create new marketplace entries instantly.
